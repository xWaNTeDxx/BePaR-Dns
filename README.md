# BePaR Windows Client 🚀

سورس کلاینت هوشمند ویندوز پروژه BePaR. این کلاینت برای اتصال به سرورهای Xray با پروتکل VLESS/XTLS-Reality و کاهش پینگ گیمینگ با رابط کاربری مدرن توسعه یافته است.

## ویژگی‌های اصلی
* **هسته قدرتمند:** استفاده از `sing-box` به عنوان موتور زیرین.
* **تزریق مستقیم به حافظه:** کانفیگ‌ها هرگز روی هارد دیسک ذخیره نمی‌شوند و به صورت استریم مستقیماً به RAM ارسال می‌شوند.
* **کاهش پینگ :** هدایت ترافیک بازی‌ها و دامنه‌های حساس به همراه تمام اتصالات UDP از طریق تونل.
* **احراز هویت بدون پسورد:** ورود به کلاینت مستقیماً با تایید در مرورگر
* **آپدیت خودکار ضد-لوپ:** دریافت فایل‌های جدید در پس‌زمینه و جایگزینی بدون باگ قفل شدن فایل.
